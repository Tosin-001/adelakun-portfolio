# Adelakun Oluwatosin Portfolio

This is a responsive, dependency-free personal portfolio website.

## Preview

Open `index.html` in a modern browser, or use a local static server.

## Updating content

- Replace `assets/brand-mark.png` to change the temporary logo/headshot.
- Update project links and copy in `index.html`.
- Keep four featured projects in `index.html`; update the complete project list in `projects.html`.
- Add project screenshots to `assets/projects/`, then change the matching card image source, for example: `src="assets/projects/verifyng.png"`.
- Replace the illustrated project cards with project screenshots when they are ready.
- Add a form provider such as Formspree or Resend before adding a contact form.

## Deployment

Upload this folder to Vercel, Netlify, GitHub Pages, or any static hosting service.
